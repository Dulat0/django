# Audio Post-Production

Make dialogue clear, consistent, and comfortable to listen to on phones and computers.

## Workflow
1. Keep an untouched copy of the original recording.
2. Remove clicks, handling noise, and distracting breaths selectively.
3. Apply gentle noise reduction only when needed; avoid metallic artifacts.
4. Use high-pass filtering only to remove rumble, not to thin the voice.
5. Apply light EQ to improve intelligibility without harshness.
6. Use moderate compression to control level differences.
7. De-ess only if sibilance is distracting.
8. Set dialogue level consistently; leave headroom and avoid clipping.
9. Mix music and effects below dialogue so every word remains intelligible.
10. Export a high-quality WAV master and a delivery format requested by the user.

## Free tools
- Audacity for recording, editing, cleanup, compression, and export.
- FFmpeg for batch conversion, trimming, joining, and format checks.
- Use only tools actually available in the user's environment; give install steps only when requested.

## Quality checks
- Listen on headphones and phone speakers.
- Check the beginning/end of every clip, edits, breaths, clipping, background noise, and loudness consistency.
- Never over-process. Natural, intelligible speech beats an artificially polished voice.
- Do not invent universal loudness targets; follow the platform or project delivery specification.

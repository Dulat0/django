# 3D Pipeline Optimizer
1. Confirm delivery format, aspect ratio, frame rate, duration, and target quality.
2. Build an asset list before modeling.
3. Approve representative character, material, environment, and lighting tests.
4. Reuse models, rigs, materials, animation cycles, and scene templates.
5. Use proxy geometry and low-quality previews during blocking.
6. Render a short test before the full sequence.
7. Cache expensive simulations and reuse approved settings.
8. Run continuity checks before final render.
Avoid invisible modeling detail, premature final renders, duplicate assets, unnecessary plugins, and long explanations. Ask only blocking questions. Be clear which tasks require Blender, Maya, Cinema 4D, Unreal Engine, or another external tool.

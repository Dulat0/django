# Emotional Dialogue Beat Mapper

Map how emotion changes from word to word and beat to beat.

## Method
1. Read the full scene and infer the character's immediate objective and knowledge.
2. Identify the trigger for each emotional change (sound, sight, memory, realization, another speaker).
3. Divide each line into playable beats.
4. Mark the exact word or pause where the emotional shift begins.
5. Give each beat a distinct intention, delivery, pace, energy, and vocal texture.
6. Check that the performance arc makes sense across the whole scene.

## Emotion palette
Use specific combinations rather than generic "emotional":
- Fear: cautious, uneasy, alarmed, panicked, frozen, pleading.
- Surprise: curious, startled, stunned, disbelieving, amazed.
- Tension: suspicious, guarded, restrained, urgent, ominous.
- Sadness: disappointed, vulnerable, grieving, quietly devastated.
- Anger: irritated, controlled, bitter, furious.
- Positive: relieved, delighted, playful, awestruck, warmly reassuring.
- Neutral: grounded, conversational, informative, matter-of-fact.

## Output format
For every line:
- Character and context
- Beat-by-beat text spans
- Emotion + intention
- Pace / pitch / volume / texture
- Breath, pause, and emphasis cues
- Transition into the next beat

Never make every line dramatic. Contrast ordinary speech with heightened emotion so the important moments land.

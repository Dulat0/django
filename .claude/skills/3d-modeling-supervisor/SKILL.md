# 3D Modeling Supervisor
- Extract all characters, props, and environments from the storyboard.
- Group assets into hero, reusable, and background-only assets.
- Specify scale, silhouette, dimensions, materials, moving parts, and pivot/origin needs.
- Identify assets that can be reused, instanced, simplified, or replaced by 2D cards.
- Model only details visible to the camera.
- Check scale consistency, naming, material organization, and animation readiness.

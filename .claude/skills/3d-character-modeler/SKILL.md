# 3D Character Modeler
For each character define role, personality, front/side/three-quarter silhouette, proportions, distinctive features, outfit, accessories, palette, materials, and expressions.
- Preserve approved design across every revision.
- Favor clean topology around shoulders, elbows, knees, mouth, and eyes for deformation.
- Define polygon/detail budget based on camera distance and delivery platform.
- Specify neutral pose, expression sheet, and turntable/reference views.
- Treat supplied reference images as the source of truth for visible design.

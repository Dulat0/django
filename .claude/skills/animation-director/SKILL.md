# Animation Director

Plan motion that supports the story while preserving the source design.

## For each shot specify
- Duration and shot size.
- Main subject movement.
- Secondary movement (hair, clothes, smoke, particles, environment).
- Camera movement, if needed.
- Start pose and end pose.
- What must remain still.

## Rules
- Use one primary action per shot.
- Prefer simple, readable movement over excessive motion.
- Preserve character identity, anatomy, clothing, background layout, and art style.
- Avoid morphing, flicker, random camera movement, and unintended new objects.
- Make transitions between shots intentional.
- If only a still image is available, propose motion that the image can realistically support.

# 3D Continuity Manager
Check character proportions, costume, accessories, rig deformation, object scale/pivots, prop positions, materials, lighting, camera lens, screen direction, timeline, frame rate, resolution, and color space.
Report only concrete issues. For each, identify shot/asset, severity, and a specific fix. Separate visual continuity from technical pipeline issues.

# Character Designer

Create characters that remain recognizable from shot to shot.

## For each character
1. Define role and one-sentence personality.
2. Specify silhouette, body proportions, face, hair, clothing, colors, and signature features.
3. Create a neutral full-body reference prompt and expression/pose sheet prompt.
4. Define details that must never change between scenes.

## Consistency rules
- Keep the same face, proportions, outfit, palette, and accessories unless the script explicitly changes them.
- Prefer simple, animation-friendly designs.
- Do not redesign a character while generating a new pose.
- If a character reference image exists, treat it as the visual source of truth.
